Cinemax



Sobre o Projeto

O CineMax é um projeto desenvolvido para disponibilizar, de maneira prática e organizada, o cadastro e a consulta de filmes e salas de cinema. O sistema permite registrar informações dos filmes, como título, diretor, ano de lançamento, gênero e duração, além de cadastrar salas de cinema com informações como número, capacidade e tipo. objetivo do CineMax é facilitar o gerenciamento dessas informações por meio de uma interface simples e intuitiva, tornando o processo de cadastro e visualização mais rápido e eficiente. Dessa forma, o projeto contribui para a organização dos dados do cinema e oferece uma maneira acessível de consultar os registros cadastrados. O sistema foi desenvolvido utilizando Python com o framework Flask para as funcionalidades da aplicação, HTML para a estrutura das páginas e PostgreSQL para armazenar os dados.
